# Commercial & Operations Transformation Dashboard

Which products and orders protect gross margin, and can production deliver them?

This independent portfolio project is at the planning stage. The proposed study uses synthetic technical-textiles manufacturing data. Implementation and evaluation are scheduled for a later build.

**Planned tools** — Power BI Desktop, Power Query, SQL and DAX.

## First milestone

Define the five KPIs and reconcile a single invoice, opportunity and production shift by hand.
